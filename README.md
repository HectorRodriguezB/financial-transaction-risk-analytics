# Financial Transaction Risk Analytics

End-to-end analytics and data science project focused on financial transaction risk and fraud analysis.

## Project Overview

The objective of this project is to analyze large-scale financial transaction data in order to identify fraud patterns, measure financial risk exposure, and support risk-related decision-making.

The project begins with a Data Analytics and Business Intelligence phase and will later evolve into a Machine Learning fraud detection solution.

## Business Goal

The main goal is to build an analytical solution that helps a Risk Operations team understand:

- How transactional activity behaves.
- Where fraudulent activity is concentrated.
- Which transaction types or accounts present higher risk.
- How much financial value is exposed to fraud.
- How effective the existing fraud flagging mechanism is.

## Planned Project Scope

The project will progressively include:

- Data acquisition and validation
- Data cleaning and transformation
- PostgreSQL database design
- SQL analytics
- Exploratory Data Analysis with Python
- Fraud and risk KPI development
- Power BI dashboarding
- Feature engineering
- Machine learning for fraud detection
- Model evaluation and business-oriented threshold analysis

## Dataset

The project will use the PaySim synthetic financial transaction dataset.

PaySim contains simulated financial transactions and includes information related to transaction type, amount, origin and destination accounts, account balances, fraud labels, and fraud flags.

A complete data dictionary will be created after the dataset has been formally acquired and inspected.
